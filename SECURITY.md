# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any wwWallet repository, please report it responsibly.

**Do not open a public GitHub issue or publicly disclose the vulnerability before it has been addressed.**

### Contact

Report security vulnerabilities by email:
**security@wwwallet.org**

### What to Include

Please include as much of the following information as possible:

- A description of the vulnerability
- The affected repository and branch, tag or version
- Steps to reproduce the issue or a proof of concept
- The potential security impact, if known
- Any suggested mitigation or fix, if available

Please avoid including sensitive vulnerability details in public issues, discussions or pull requests.

Thank you for helping keep wwWallet and its users secure.
